⚡ 快传 P2P

网页版点对点传输：文件直接从一台设备到另一台设备，不经过任何服务器。 双方互换两段「邀请码/应答码」即可建立通道。同一机房局域网内速度最快；跨网络需能打通 NAT（多数家庭/办公网络可以）。
我是发送方选文件 → 生成邀请码 → 等对方应答
我是接收方贴邀请码 → 回应答码 → 收文件

隐私说明：文件内容走 WebRTC 数据通道（DTLS 加密），服务器只在你打开本页面时提供了一次网页文件本身， 不参与文件传输。
若连接一直「连接中」：换一个网络试试（部分对称 NAT 无法直连），或回到机房用桌面版（局域网 HTTP 直传，更稳）。
